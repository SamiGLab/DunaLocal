# Shared navigation and footer / Local SEO example

All 22 HU/EN pages now use the same light footer, preserving service and company navigation. Localized detail headers match the homepage logo, typography, palette, language links and contact action. Homepage navigation still uses section anchors; detail navigation uses corresponding dedicated pages. Language switching keeps the corresponding route.

The HU/EN Local SEO hero uses existing owner-supplied Local SEO artwork with real HTML headings, description and working contact/detail links. Other inner-page heroes and page body copy were intentionally retained for the next review.

Existing canonical URLs, hreflang, sitemap, GSC verification, robots and noindex stay unchanged. No forms, tracking or external image dependencies were added.
